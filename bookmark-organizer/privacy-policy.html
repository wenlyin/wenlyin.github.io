书签整理助手 · 隐私政策

生效日期：2026 年 10 月 28 日 · 适用于 Microsoft Edge / Chrome 扩展“书签整理助手”

“书签整理助手”（以下简称“本扩展”）用于检查书签链接是否失效、整理书签分类。本政策说明本扩展访问哪些数据、如何使用这些数据，以及你可以如何控制它们。

1. 本扩展访问的数据

  • 书签数据：书签的标题、网址、所在文件夹及文件夹结构。这是实现扫描、分类、移动和删除功能的必要条件。
  • 扩展设置：扫描选项、分类规则、界面偏好，以及你主动填写的 AI 服务地址、模型名称和 API Key。
  • 本地运行记录：扫描结果、分类建议、最近一次移动/删除的撤销记录。

本扩展不读取你的浏览历史、不读取网页正文、不记录键盘输入、不访问密码、支付信息或其他浏览器数据。

2. 数据如何存储

上述数据全部保存在浏览器提供的本地存储 chrome.storage.local 中，仅保存在你的设备上。开发者不运营任何用于接收、存储或分析这些数据的服务器。

API Key 同样只保存在本地，不会随书签备份文件导出，也不会发送给开发者。

3. 何时会发生网络请求

3.1 失效链接扫描（你主动触发）

当你点击“扫描全部书签”时，本扩展会向书签中的 HTTP/HTTPS 网址发起请求，以判断页面是否返回 404/410、是否无法连接或超时。这些请求会直接发送到对应网站，因此该网站会像正常访问一样看到你的 IP 地址、User-Agent 等常规请求信息。本扩展只读取 HTTP 响应状态，不读取页面正文。扫描不会在后台自动进行。

3.2 智能分类（可选，默认关闭）

只有当你主动配置 OpenAI 兼容的服务地址和 API Key，并点击“智能分类”时，本扩展才会把待分类书签的标题、网址、所在文件夹名称以及现有文件夹列表发送到你指定的那个服务端点，用于生成分类建议。API Key 会作为请求凭据发送给同一端点。

该端点由你自行选择，可能是第三方 AI 服务商或你本机运行的 Ollama。数据在该端点如何处理，取决于该服务商的隐私政策，开发者无法控制。如果你不启用此功能，本扩展不会向任何第三方发送书签数据。

3.3 打开外部搜索（你主动点击）

当你点击“查找同类网站”时，本扩展会在新标签页打开 Bing 搜索，并把书签标题作为搜索词。该查询会发送给 Bing。

4. 数据共享与出售

  • 开发者不会收集、接收、出售、出租或交易你的任何数据。
  • 本扩展不包含广告、分析统计、遥测、崩溃上报或任何开发者运营的追踪服务。
  • 除上述“你主动触发的请求”外，不会向第三方共享数据。

5. 数据保留与删除

本地数据会一直保留，直到你在扩展设置中清除、清除浏览器扩展数据、卸载本扩展，或删除对应书签。撤销记录只保留最近一批操作，并在下一次同类操作时被替换。开发者侧没有可删除的数据副本，因为开发者不接收这些数据。

6. 权限说明

  • bookmarks：读取书签树，移动书签、创建文件夹、删除你确认删除的书签。
  • storage：在本地保存设置、扫描结果和撤销记录。
  • http://*/*、https://*/*：仅用于在扫描时请求书签网址，判断链接是否失效。

7. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 政策变更

如果本扩展的数据处理方式发生实质变化，本页面会更新并修改生效日期。重大变更会在扩展更新说明中提示。

Privacy Policy

Effective: October 28, 2026 · For the “Bookmark Organizer” extension

Bookmark Organizer checks whether saved bookmarks are still reachable and helps organize them into folders. This policy explains what data the extension accesses and how it is handled.

1. Data the extension accesses

  • Bookmark data: bookmark titles, URLs, folder names, and folder structure. This is required to scan, classify, move, and delete bookmarks.
  • Settings: scan options, classification preferences, and, if you choose to use the optional AI feature, the endpoint URL, model name, and API key you enter.
  • Local records: scan results, classification suggestions, and undo records for the most recent move or delete operation.

The extension does not read your browsing history, page content, keystrokes, passwords, payment information, or other browser data.

2. Storage

All data is stored locally in chrome.storage.local on your device. The developer does not operate any server that receives, stores, or analyzes this data. Your API key is stored locally and is not included in bookmark backup exports.

3. Network requests

3.1 Dead-link scan (user-initiated)

When you click “Scan all bookmarks,” the extension requests each bookmarked HTTP/HTTPS URL to determine whether it returns 404/410, is unreachable, or times out. These requests go directly to the bookmarked websites, which will see your IP address and standard request headers. The extension reads only the HTTP status, not page content. Scans never run automatically in the background.

3.2 Optional AI classification (off by default)

Only after you configure an OpenAI-compatible endpoint and API key and click “Smart classify,” the extension sends the titles, URLs, and folder names of the bookmarks being classified, plus the list of existing folders to the endpoint you specified. Your API key is sent to that same endpoint as credentials. The endpoint may be a third-party AI provider or a local Ollama instance. How that provider handles the data is governed by its own privacy policy; the developer does not control it. If you do not enable this feature, no bookmark data is sent to any third party.

3.3 External search (user-initiated)

When you click “Find similar sites,” the extension opens a Bing search in a new tab using the bookmark title as the query.

4. Sharing and sale of data

  • The developer does not collect, receive, sell, rent, or trade any of your data.
  • The extension contains no ads, analytics, telemetry, crash reporting, or developer-operated tracking.
  • No data is shared with third parties except for the user-initiated requests described above.

5. Retention and deletion

Local data remains until you clear it in the extension, clear the extension’s browser data, uninstall the extension, or delete the corresponding bookmarks. Undo records keep only the latest operation and are replaced by the next one. The developer holds no copy to delete because none is received.

6. Permissions

  • bookmarks: read the bookmark tree; move bookmarks, create folders, and delete bookmarks you explicitly confirm.
  • storage: save settings, scan results, and undo records locally.
  • http://*/*, https://*/*: request bookmarked URLs during a user-initiated scan to detect dead links.

7. Children

The extension is not directed to children under 13 and does not knowingly collect personal information from children.

8. Changes

If data practices change materially, this page will be updated with a new effective date. Significant changes will be noted in the extension’s update notes.
